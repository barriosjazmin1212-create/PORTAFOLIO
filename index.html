App móvil · 2026

COFEI CAFETERIA

Diseño UI/UX · Mobile App

Diseño de una aplicación móvil para una cafetería, enfocada en simplificar el proceso de pedido y pago digital.

El proyecto surge a partir de una problemática frecuente: interfaces poco claras, demasiados pasos y falta de confirmación durante el pago, situaciones que pueden generar confusión y hacer perder tiempo al usuario.

A partir del análisis del usuario y sus necesidades, desarrollé una experiencia de navegación más simple y guiada, organizando el flujo en tres etapas principales: pedido → pago → confirmación.

El objetivo fue crear una interfaz clara, visual e intuitiva, que permitiera completar una compra de manera rápida y segura, reduciendo fricciones durante la experiencia.

BAIT PISOS · UX/UI - WEB

BAIT Pisos & Deco — E-commerce

Desarrollo y rediseño UX/UI de una tienda online para una empresa de pisos, cerámicos, decks y revestimientos.

El proyecto comenzó con un análisis UX del sitio existente para detectar problemas de navegación, jerarquía visual y exploración del catálogo. A partir de estos hallazgos, se reorganizó la arquitectura de información y se diseñó una experiencia diferenciada para clientes minoristas y mayoristas.

La solución incluyó una nueva estructura de categorías y productos, un hero con CTA, fichas de producto optimizadas, un portal B2B con formulario de cotización y una calculadora interactiva para determinar la cantidad de cajas necesarias según los metros cuadrados.
